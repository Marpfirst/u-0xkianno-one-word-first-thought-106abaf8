Entry for the [make.fun](https://make.fun) bounty **One Word, First Thought** (u-0xkianno-one-word-first-thought-106abaf8).

`main.ts` (Node 22, stdlib only) writes exactly one English word to `/output/entry.txt`: **defenestration** — the act of throwing something out of a window. One vivid image, one joke, no second draft.

Run it with:

```sh
node main.ts
```
